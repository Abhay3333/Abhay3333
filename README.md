### 🏆 Featured Project: LogLogic
<a href="[https://github.com/Abhay3333/Loglogic](https://github.com/Abhay3333/Loglogic-Frontend-)">
  <img align="center" src="https://github-readme-stats.vercel.app/api/pin/?username=Abhay3333&repo=Loglogic&theme=vue-dark&show_icons=true&hide_border=true" />
</a>

**LogLogic** is a high-speed "digital flight recorder" for software applications. 
* **The Problem:** Modern apps generate millions of logs across dozens of microservices, making debugging an absolute nightmare.
* **The Solution:** An indestructible ingestion funnel using a Node.js/Express API gateway, a Redis (BullMQ) memory buffer to prevent crashes during traffic spikes, and MongoDB for storage. Includes a real-time Server-Sent Events (SSE) live-tail dashboard, multi-tenant Row Level Security (Supabase), and an automated alerting engine that dispatches to Slack via interactive HMAC-verified webhooks.
